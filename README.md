# Synthe · AFTERHOURS

Rage synth (VST3 + AU, macOS) from the **AFTERHOURS** pack. Same engine as the browser prototype: up to 9 detuned
saws per note with stereo spread, octave layer, sub, click and pitch "zap", filter + amp envelopes shaped per preset,
drive (4x oversampled), OTT, mono low end, ping-pong delay, reverb, tempo pump and GLITCH (stutter, tape stop,
bitcrush, laser zaps, chops, filter sweeps, octave jumps). 21 presets in LEAD / STAB / PLUCK / PAD.

Every push builds the plugin with `.github/workflows/build-mac.yml`. Download `Synthe-mac` from the Actions run,
unzip and double-click `install.command` (or follow `INSTALL.txt`). The plugin shows up under **AFTERHOURS**.
